# C5 逻辑思维建模 · 初赛在线练习系统

**在线访问：https://asteroidhaha.github.io/c5-logic-quiz/**

全国青少年科学探究建模能力大赛（2025-2026 学年）**C5 逻辑思维建模（含幼小衔接专项）** 初赛备考练习系统。

依据大赛组委会官方《C5 赛项说明》命制 200 道模拟练习题，覆盖初赛三大素养考察范围：

- **科学常识**（60 题）：动植物认知 / 材质与轻重 / 四季天气 / 声光现象 / 安全卫生
- **基础探究方法**（50 题）：观察对比 / 分类排序 / 结果预判
- **逻辑思维基础**（90 题）：图形与数列规律 / 顺序推理 / 等量代换与天平 / 分类归纳 / 正误判断 / 生活逻辑与枚举

> 本题库为按官方考试范围命制的模拟练习，非官方真题。

## 功能

- **分类练习**：左侧按大类 / 子题型筛选，即时判分 + 答案解析，支持打乱顺序刷题
- **模拟考试**：随机抽 20 题（与正式初赛同规则：单选、每题 5 分、答错不扣分），60 分钟倒计时、答题卡跳题、交卷出分、逐题回顾

## 技术栈

React + TypeScript + Vite + Tailwind CSS + shadcn/ui

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build   # 输出 dist/ 静态站点
```
